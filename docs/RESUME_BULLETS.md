# 简历项目描述

> 正式简历数字只从官方 BigQuery 导出后的 `artifacts/pipeline_summary.json` 读取。`fixture_*` 结果不可写入简历。

## 数据分析 / BI

- 基于 Google 官方 GA4 电商事件数据，统一用户、会话、订单、收入和顺序漏斗口径，搭建趋势、渠道、留存队列、商品与用户价值看板，并用异常检测定位波动日期。

## 数据开发 / 数仓

- 使用 BigQuery SQL 解析 `event_params` 与 `items` 嵌套数组，结合 DuckDB 构建 ODS→DWD→DWS→ADS 四层模型，落地事件去重、会话识别、窗口函数漏斗/留存和 12 条自动质量规则，导出标准 Parquet 契约。

## 央国企数据与数字化

- 将埋点原始事件沉淀为口径可追溯、质量可核验、可复用的数据资产，形成指标字典、数据血缘、接口与经营看板完整交付。
