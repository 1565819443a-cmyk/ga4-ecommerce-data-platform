# 简历项目描述

以下数字来自 2026-09-01 对 Google 官方 GA4 BigQuery Sample Ecommerce 的实际全量运行；证据位于 `artifacts/`，fixture 数字不用于简历。

## 数据分析 / BI 版

- 基于 Google 官方 GA4 电商数据搭建经营分析体系，处理 2020-11—2021-01 共 4,295,584 条事件、3,982,732 条商品明细，统一 270,154 位用户、360,129 个会话、4,452 个订单和 $362,165 收入口径。
- 构建浏览→商品→加购→结账→购买有序漏斗、周留存、渠道、商品、RFM 与异常监控看板，识别 1.35% 会话转化率、4.29% 次周加权留存及 3 个用户量异常日期，并明确混淆样例不能作因果解释。

## 数据开发 / 数仓版

- 使用 BigQuery SQL 解析 `event_params` 与 `items` 嵌套数组，采用 Arrow 流式导出与 ZSTD Parquet 降低内存占用，结合 DuckDB 建设 ODS→DWD→DWS→ADS 四层模型及标准 Parquet 数据契约。
- 落地事件幂等去重、用户会话识别、窗口函数漏斗/留存、渠道与用户价值模型；执行 19 条质量规则，正式数据 17 通过、2 警告、0 失败，并保留源数据异常的审计记录。

## 央国企数据与数字化版

- 将 4.3M 级公开埋点事件沉淀为口径、血缘、质量和版本可追溯的数据资产，交付指标/字段字典、FastAPI 服务、ECharts 经营看板、自动化测试与 GitHub Actions。
- 通过提取作业清单、文件 SHA-256、处理摘要和质量报告建立可复核证据链，避免以测试 fixture 或未经验证的统计数字替代正式结果。

## 使用建议

一份简历选择对应岗位的 2 条即可。不要把 Google 混淆样例写成真实公司的经营增长，也不要声称分析带来了收入提升。
